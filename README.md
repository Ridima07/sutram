# EVENTRA

### AI-Powered Digital Forensics & Investigation Platform

EVENTRA is a digital forensics platform designed to organize digital evidence, identify anomalous activities, explore relationships between evidence, and reconstruct incident timelines.

## Key Features

- Anomaly Detection
- Entity Extraction
- Cross-Source Evidence Correlation
- Evidence Graph Visualization
- Case Reconstruction
- Evidence Integrity and Support Classification

## Project Goal

EVENTRA aims to help investigators connect fragmented digital evidence, identify suspicious patterns, verify supporting evidence, and reconstruct the sequence of events during an incident.

## Current Prototype

The prototype uses synthetic forensic evidence from multiple sources to demonstrate digital investigation workflows.
