\# SUTRAM



\### AI-Powered Digital Forensics Investigation Framework



SUTRAM is a prototype digital forensics investigation framework designed to collect, analyze, authenticate, and correlate digital evidence from multiple sources.



\## Key Features



\- Anomaly Detection

\- Entity Extraction

\- Cross-Source Evidence Correlation

\- Evidence Graph Visualization

\- Case Reconstruction

\- Evidence Integrity and Support Classification



\## Project Goal



The framework helps investigators connect fragmented digital evidence, identify suspicious patterns, verify supporting evidence, and reconstruct the sequence of events during an incident.



\## Current Prototype



The prototype uses synthetic forensic evidence from multiple sources such as:



\- System logs

\- File access logs

\- USB activity

\- Network logs



These observations are normalized, correlated across sources, and used to reconstruct a chronological incident timeline.



> This project is a prototype developed for demonstration and hackathon purposes. The forensic data used is synthetic.
